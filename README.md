MM is a multifunctional Frida toolkit that consolidates multiple analysis and bypass capabilities into a single script. Portions of its code are adapted from third-party sources, enhanced, and integrated by me. With a single execution, this tool enables Java class instrumentation, full Dalvik class extraction and hooking, and the bypass of common protections such as root detection, SSL pinning, and cryptographic library monitoring for analysis purposes.
This tool addresses a practical limitation in some applications where multiple Frida scripts cannot be attached simultaneously due to the app’s security architecture. By running MM with the -f option, all supported instrumentation and bypass features can be applied through a single script.
Obson is a Frida-based script used for monitoring and analyzing JSON-related classes within an application during runtime.
SStream is a Frida-based script used for instrumenting and analyzing libraries related to SSL socket stream communication during runtime.
STrak is a Frida-based script used to capture application stack traces at runtime for analysis purposes. It can sometimes reveal critical strings, logic paths, or sensitive values useful during dynamic analysis.
